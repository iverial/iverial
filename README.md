# Hi 👋, I'm Ivan Caggiano

**Backend Developer · .NET · SQL Server · NestJS** — Buenos Aires, Argentina

I build the APIs and internal systems that operations teams use every day. I have 2+ years of professional experience, mostly with ASP.NET Core and SQL Server, and a solid background in Node.js and NestJS.

I'm currently at **Grupo Jardín del Pilar**, where I build end to end the tools used by the Collections, Sales and Management Control teams:

- Reporting dashboards backed by nightly processes that consolidate ERP and CRM data.
- A collections campaign platform integrated with the call center: contact lists, automatic dialers, IVR and email.
- Query and index tuning in SQL Server: searches that took 3 to 5 seconds now run in under half a second.
- Deployments with Docker, GitHub Actions and Nginx on Linux servers.

## Featured project

### [RequestMap](https://requestmap.vercel.app/) · [code](https://github.com/iverial/requestmap)

An interactive map of a backend architecture. Send a request and watch it travel hop by hop through a reverse proxy, API gateway, auth service, cache, database and message queue, with a trace of every hop. Then break something and see how the system reacts: cache misses, expired tokens, retries and a circuit breaker.
